# 🛒 Supermarket Sales Dashboard

**Access Live Dashboard Here:** https://tinyurl.com/mws5hy8v

## 📊 Project Overview
This Power BI dashboard provides an interactive analysis of supermarket sales performance, enabling users to explore revenue trends, product performance, and customer purchasing patterns through dynamic visualizations and KPIs.

The dashboard is designed to support data-driven decision-making by transforming raw sales data into actionable business insights.

---

## 📈 Dashboard Features
* Sales performance monitoring
* Revenue trend analysis
* Product category analysis
* Customer purchasing insights
* Interactive filtering using slicers
* KPI cards for quick performance tracking
* Visual comparison of sales metrics

---

## 📊 Visualizations Included
* Clustered Bar Chart
* Line Chart
* Column Chart
* Donut Charts
* KPI Cards
* Interactive Slicers

---

## 🎯 Key Business Insights
The dashboard helps stakeholders:
* Identify top-performing products and categories
* Analyze sales trends over time
* Monitor overall business performance
* Compare sales across different segments
* Support strategic decision-making
