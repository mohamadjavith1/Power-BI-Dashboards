\# \*\*🛒 Supermarket Sales Dashboard – Business Performance Insights\*\*



\## 📊 Project Overview



This Power BI dashboard provides a comprehensive analysis of supermarket sales performance. It enables stakeholders to monitor revenue, track product performance, and analyze customer purchasing behavior across regions and time periods.



The dashboard is designed to support data-driven decision-making by presenting key metrics and trends in a clear and interactive format.



\---
