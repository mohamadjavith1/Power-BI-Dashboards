\# \*\*🌦 Live IoT Weather Dashboard – Real-Time Analytics System\*\*



\## 📊 Project Overview



This project is a real-time weather dashboard powered by a custom-built IoT weather station. Unlike traditional dashboards that rely on static datasets, this system captures live environmental data and transforms it into actionable insights through Power BI.



It demonstrates a complete pipeline from physical sensors to interactive data visualization.



\---



\## ⚙️ Technical Overview



\### 📡 Data Collection



Built using an ESP8266 microcontroller with DHT11 and BMP280 sensors to capture real-time Temperature, Humidity, and Pressure data.



\### ☁️ Cloud Integration



Sensor data is continuously pushed to Google Sheets, enabling seamless real-time data flow into the dashboard.



\### 🌍 Region-Specific Calibration



Calibrated specifically for the tropical climate of Trichy, Tamil Nadu to ensure higher accuracy compared to generic weather APIs.



\### 🧮 Advanced Analytics



Developed custom DAX measures to calculate:



\* Heat Index ("Feels Like" temperature)

\* Dew Point

\* Weather trend patterns



\### 📊 Dynamic Visuals



Includes weather-based icons and automated refresh mechanisms to ensure up-to-date visualization.
